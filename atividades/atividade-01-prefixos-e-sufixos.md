# 📝 Atividade 1 — Prefixos e Sufixos

## Enunciado

Considere a palavra:
```
ab
```

**Pergunta:** Liste os prefixos e sufixos.

---

## ✍️ Resolução

**Prefixo** = pedaço que começa no **início** da palavra. Vou pegando desde o
vazio até a palavra inteira:

- `ε` → o prefixo vazio (sempre conta)
- `a` → primeiro símbolo
- `ab` → a palavra toda

**Sufixo** = pedaço que termina no **final** da palavra. Mesma ideia, mas
olhando do fim:

- `ε` → o sufixo vazio (sempre conta)
- `b` → último símbolo
- `ab` → a palavra toda

---

## ✅ Gabarito

**Prefixos:**
```
{ε, a, ab}
```

**Sufixos:**
```
{ε, b, ab}
```
